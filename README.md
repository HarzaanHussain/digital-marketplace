# Digital Item Marketplace

A web application for buying and selling digital items with an alert system.

## Features

- User authentication and profile management
- Digital item listings with categories
- Purchase system for digital items
- Reviews and ratings
- Alert system for price drops, new items, etc.

## Technologies

- Backend: Node.js, Express
- Database: MySQL (hosted on Railway)
- Frontend: HTML, CSS, JavaScript

## Setup

1. Clone the repository
2. Install dependencies: `npm install`
3. Set up environment variables in `.env` file
4. Run the application: `npm run dev`
